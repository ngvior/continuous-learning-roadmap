The Claude Academy bundle that covers the agent-tooling layer: Claude Code in Action (long hands-off sessions, CLAUDE.md, permissions, scheduled runs, plugins), Introduction to Model Context Protocol and its Advanced Topics follow-up (building MCP servers and clients with tools, resources and prompts), Introduction to subagents, and Introduction to agent skills. Together they map onto the Claude Certified Architect Foundations blueprint domains for tool design, MCP integration and Claude Code workflows; the exam itself is partner-gated and is not a Node. Completion is checkable through the free, non-expiring course badges. It is a Prerequisite of the P15 Agent Orchestration System, whose tool registry and MCP integration reuse these patterns.
