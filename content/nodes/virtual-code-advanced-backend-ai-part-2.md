The first 4.5 hours of VIRTUAL CODE's second course video, scoped to Level 4: LLM fundamentals, LangChain and prompt engineering; LangGraph agents and graph state; and RAG with vector embeddings, Qdrant, semantic search and chat over PDFs and websites, all from an Express server in JavaScript. It is the only Resource on the Roadmap that shows backend-for-AI patterns from the server side in the JavaScript ecosystem, so it bridges the Backend and AI Engineering Lanes; porting its patterns to NestJS and TypeScript is left to the owner on purpose. The cloud-deployment half (AWS, GitHub Actions, ECR and ECS) is out of scope because CDK and pipelines are daily work. It comes after the P6 RAG Pipeline so the LangGraph and Qdrant material is read with a working RAG system already in hand, and it is a Prerequisite of the P15 Agent Orchestration System.
